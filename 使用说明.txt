校园网 CampusLink 1.1.4
适用：喀什大学当前 Dr.COM 校园网，Windows 10 2004 / Windows 11，x64。

安装版：运行 CampusLink-1.1.4-Setup-x64.exe，按向导安装。
便携版：先把整个 ZIP 解压到一个文件夹，再双击 CampusLink.exe。
请保留 EXE 周围的运行库文件，不要只拷贝 EXE，也不要直接在 ZIP 中运行。
两种版本均附带所需的 Windows App SDK 运行文件，不需要另外安装 .NET。

第一次使用
1. 连接学校 Wi-Fi 或网线。
2. 输入平时在学校登录网页使用的账号密码，点击“一键登录”。
3. 勾选“在这台电脑上记住账号密码”后，认证成功会保存至 Windows 凭据管理器。
4. 如果当前已经在线，也可以点击“保存账号”，为下次连接做好准备。

窗口与偏好设置
左侧“校园网连接”查看状态、填写账号；左侧“偏好设置”调整自动登录和成功后关闭。
宽窗口并排显示状态与账号，缩窄后自动上下排列；窄窗口可用左上角菜单展开导航。

日常使用
有已保存账号且开启“打开应用时自动登录”时，双击应用即可自动认证。
已经在线会跳过认证，不会注销网络或重复提交登录。
默认成功后 4 秒关闭窗口；操作窗口可取消关闭，也可在“偏好设置”中关闭此功能。
应用退出后不驻留。默认不开机启动，可在偏好设置中开启开机连接。网络不可达、密码错误时会显示提示，不自动反复提交密码。

校园 Wi-Fi 与有线网入口
软件会检查学校已确认的常用入口 172.17.1.90；入口无法连接或状态格式不匹配时，再检查有线入口 172.31.0.10。
如果入口能返回状态，却无法获取当前设备信息或认证配置，也会在提交密码前尝试另一个入口。
同一窗口会优先使用上次成功识别的入口。每次登录、注销和结果核对固定在该次选定的入口，不因请求失败换入口重复登录。
每个人的 IP 和设备信息从当前入口读取，无需修改地址或填写他人的登录网址参数。
如果两个入口均可访问，软件优先使用当前窗口上次识别的入口，首次打开优先使用常用入口。

网页能打开，但软件仍提示无法连接
1. 点击连接页的“网络诊断”，等待检查两个入口的状态及配置接口。
2. 点击“复制结果”，把文字发给开发者排查。
诊断不会登录或注销，也不会读取已保存密码；报告不包含账号、密码、设备 IP 或 MAC，不会自动上传。
网页登录正常不代表 801 端口的认证接口也可访问；错误提示会标明入口、端口及 Windows / HTTP 错误码。
如果当前入口的认证方式暂不支持，请先使用“打开学校登录页”或“打开有线网备用入口”。
新发现的有线入口仍需实际环境验证；不保证覆盖学校所有接入区域及不同认证方式。

状态动画
连接时显示进度环与轻微呼吸，成功时显示绿色勾选并扩散一次光晕，失败时短暂轻晃。
状态文字同步淡入。动画遵循 Windows 的“动画效果”开关；关闭时保留完整静态提示。

明暗主题
窗口内容和原生标题栏跟随 Windows 的应用明暗主题，切换时会同步更新。
高对比模式保留系统标题栏配色。较早 Windows 版本的标题栏效果取决于系统支持情况。

开机连接与注销
先在连接页点击“保存账号”，再到左侧“偏好设置”开启“开机启动并自动连接”。
该开关在当前 Windows 用户登录后启动应用，并使用已保存账号连接校园网；开启此项后，开机连接独立于手动打开时的自动登录开关。
开机时会短暂等待校园网就绪，认证被拒绝后不重复提交密码。需要先连接学校 Wi-Fi 或网线。
便携版移动文件夹后，请在新位置重新开启开机连接。清除本机账号会同时关闭开机连接。
连接页的“注销校园网”会先询问确认，按学校配置注销并核对离线状态；学校启用注销解绑时，会解除本机自动认证绑定，已保存在 Windows 的账号密码会保留。
注销后本次不会自动重新连接，下次登录 Windows 或手动打开应用时仍按偏好设置执行。
“刷新状态”只检查当前在线情况，不提交密码。

免责声明
应用左侧可查看“免责声明”，分享包也附有同名文本。请在使用和分享前阅读。

账号与分享
分享安装程序或原始便携 ZIP 即可，不包含制作者的个人账号。
每个人都需要在自己的电脑填写账号密码。
密码存入当前 Windows 用户的凭据管理器，不放进便携文件夹。
同一电脑、同一 Windows 用户下的安装版和便携版共用账号与偏好设置。
其他以同一 Windows 用户运行的程序也可能访问凭据管理器，这不是程序间的隔离保险箱。
学校接口目前是 HTTP，登录传输方式与学校原网页相同；只连接学校已确认的 172.17.1.90 与 172.31.0.10 的 80 / 801 端口。
应用不添加遥测、广告、云端账号同步或第三方登录服务器。

修改或删除账号
修改输入框后点击“保存账号”。点击“清除本机账号”只删除本机保存的凭据，不修改学校密码、不注销网络。
卸载前可先清除本机账号。卸载应用默认保留凭据和偏好，便携版仍可继续使用。
偏好设置文件：%LOCALAPPDATA%\CampusLink\settings.json（不含密码）。

这是非官方辅助工具，不代表学校。校园网政策、账户限制和接口变化仍以学校为准。
尚未提供商业代码签名；安装程序在首次分发的电脑上可能显示“未知发布者”。

注销诊断记录：%LOCALAPPDATA%\CampusLink\last-logout.log，只记录操作阶段、时间和是否成功，不记录账号、密码、IP、MAC 或网关原始响应。每次注销时覆盖上一条记录。
